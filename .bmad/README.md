# Project-specific BMAD notes (not an installation)

The **official** BMAD installer (`npx bmad-method install`) creates `_bmad/` and selected tool skills/configuration. Do not put custom surrogate BMAD agents, workflow templates or copied upstream files here.

Read `../docs/development/bmad-codex.md` for setup. Use `../docs/` as reviewed product input when running BMAD planning; the installer-configured output directory (commonly `_bmad-output/`) is reserved for generated planning and implementation artifacts.
